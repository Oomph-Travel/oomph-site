# Oomph Travel

This is the WordPress rebuild of oomphtravel.com on SiteGround + Kadence Pro. All custom work lives in the `oomph-child` theme at `wp-content/themes/oomph-child/`. Deployment runs through GitHub Actions over SSH; Rank Math handles SEO and Microsoft Clarity covers CRO measurement.

See [BUILD-PLAN.md](BUILD-PLAN.md) for the full build plan.

## Getting started

Local dev setup, including the WordPress stack assumption (Local by Flywheel or wp-env) and the symlink to the child theme, is documented in [BUILD-PLAN.md §4](BUILD-PLAN.md#4-local-development-environment).
